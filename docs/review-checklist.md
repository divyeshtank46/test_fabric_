# Pull request review checklist

Use this checklist when reviewing a change in this repository.

- Check that the title explains the change.
- Read the description and confirm it says why the change was made.
- Open each changed file and check that the content is clear and relevant.
- Look for accidental secrets, personal data, or unrelated edits.
- If something needs fixing, leave a specific comment and request changes.
- Approve only after the change looks correct; merge after the required review is complete.

For this practice change, there is no Fabric data or workspace configuration to run. The purpose is to practice branches, pull requests, and reviews in GitHub.
